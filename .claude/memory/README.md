# hycu — the organisation's memory

**Durable memory, disposable instance.** No session remembers anything; the files do. A fresh
officer reads these in order and starts with the organisation's judgment intact.

| kind of memory | file | who appends |
|---|---|---|
| What Wyatt has DECIDED, with the reason | [`DECISIONS.md`](DECISIONS.md) | anyone, the moment he rules |
| Verdicts on the work — newest at the TOP | [`../CEO-REVIEWS.md`](../CEO-REVIEWS.md) | the CEO, after every review |
| Facts about this repo the officers need | [`../OFFICERS.md`](../OFFICERS.md) | when the repo changes |
| What is open | [`../BACKLOG.md`](../BACKLOG.md) | whoever finds it |
| What is waiting on him | [`../CTO-QUESTIONS.md`](../CTO-QUESTIONS.md) | anyone who needs him |

**Point, do not restate.** If a fact lives in one of these, link to it.

## Reading order for a fresh officer

1. `DECISIONS.md` — so you do not re-open a settled question.
2. The top of `../CEO-REVIEWS.md` — the last verdict, and whether a fault is recurring.
3. `../OFFICERS.md`.

**A checkpoint his existing rulings already answer is NOT a reason to stop.** Resolve it from this
record, name the ruling you used, and keep going.
